# Stone Paper Scissors Game

A simple command-line **Stone, Paper, Scissors** game written in Python.
Play against the computer, which randomly chooses one of the three
options. The game displays ASCII art for each choice and announces
whether you win, lose, or draw.

## Features

-   Play against a computer opponent.
-   Computer choices are randomized.
-   ASCII-art illustrations for stone, paper, and scissors.
-   Displays the result of each round.
-   Checks that the selected option is within the valid range.

## Requirements

-   Python 3

## How to Run

1.  Download or clone this repository.

2.  Open a terminal in the project folder.

3.  Run:

    ``` bash
    python "stone paper scissors.py"
    ```

    On some systems, use `python3` instead of `python`.

## How to Play

When prompted, enter the number for your choice:

  Number   Choice
  -------- ----------
  `0`      Stone
  `1`      Paper
  `2`      Scissors

The computer will randomly select its choice, and the program will
display the outcome.

## Rules

-   Stone beats Scissors.
-   Scissors beats Paper.
-   Paper beats Stone.
-   Matching choices result in a draw.

## Project File

-   `stone paper scissors.py` --- Main Python game program.
